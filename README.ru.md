# sito

**Визуальный модульный конвейер для работы с семантическим ядром.** Загрузите список ключевых
слов или соберите его с нуля. Дальше он проходит через стопку шагов: очистка, классификация любой
LLM, сбор выдачи Google, кластеризация, экспорт. На любом шаге можно отредактировать данные,
перезапустить шаг, откатить его, импортировать и экспортировать результат.

*Сито* — потому что каждый шаг работает как сито: задерживает часть запросов (с указанием причины)
и пропускает остальные дальше. Интерфейс показывает это наглядно: сколько запросов пришло на шаг,
сколько он задержал и почему, сколько прошло.

- **Локально.** Работает на вашей машине с вашими ключами. Без аккаунтов и телеметрии.
- **Любая модель.** OpenAI, Anthropic, OpenRouter, DeepSeek или локальные Ollama / LM Studio.
- **Ничего не теряется.** Шаги не удаляют запросы, а помечают их как задержанные. Перед каждым
  запуском и после него сохраняется снапшот, любой из них можно восстановить или выгрузить.
- **Контрольные точки везде.** Выгрузили результат после любого шага, поправили в Excel, загрузили
  обратно.
- **Плагины на чистом Python.** Шаг или коннектор — это один класс. Форма настроек строится
  автоматически из pydantic-модели, фронтенд писать не нужно.

> Статус: 0.1, ранняя версия. Основной сценарий работает целиком и покрыт тестами. До 1.0 возможны
> шероховатости и изменения API плагинов.

## Быстрый старт

```bash
pip install git+https://github.com/Black-coffe/sito.git
sito serve                     # → http://127.0.0.1:8765
```

Или через Docker:

```bash
git clone https://github.com/Black-coffe/sito.git && cd sito
docker compose up -d           # → http://127.0.0.1:8765, данные в томе sito-data
```

Чтобы осмотреться, ничего не подключая, запустите `sito demo`. Команда создаст пример проекта,
прогонит весь конвейер на офлайн-демо-коннекторах и запустит приложение. Ключи для этого не нужны:
AI-ответы и выдача в демо синтетические.

Для реальной работы:

1. Создайте проект и в одном абзаце опишите бизнес: что продаёте, кому и где. По этому описанию
   AI-шаги оценивают релевантность.
2. Нажмите **Import** и загрузите выгрузку Ahrefs / Semrush / Keyword Planner, любой CSV или XLSX,
   либо вставьте список.
3. В разделе **Connections** добавьте ключи. На странице каждого провайдера написано, где взять ключ,
   а кнопка **Save and test** сразу его проверит.
4. Нажмите **Run all** или запускайте шаги по одному.
5. Выгрузите результат в Excel, CSV или JSON. Это можно сделать сразу или позже из любого снапшота.

Интерфейс и документация сейчас на английском. Полная документация встроена в приложение
(раздел *Docs*) и лежит в [`src/sito/docs`](src/sito/docs).

## Встроенные плагины

| Шаг | Что делает |
|---|---|
| Add keywords manually | Добавить список вручную. |
| Autocomplete expansion | Расширить ядро подсказками Google: сиды, a–z, вопросительные префиксы. |
| Clean & normalize | Приводит к нижнему регистру, убирает спецсимволы и дубли, задерживает слишком короткие и длинные запросы, запросы из одних цифр и запросы со стоп-словами. |
| Filter by rules | Фильтр по частотности, KD, CPC, любому полю (например `relevance >= 6`), вхождению слов. |
| AI classification | Релевантность бизнесу 1–10, интент, ваши категории, язык и любые дополнительные поля. Работает пачками, параллельно и продолжается с места остановки. |
| Collect SERP | Топ-10 Google по каждому запросу. Можно добавлять в ядро «похожие запросы» и «People also ask». |
| Cluster by SERP overlap | Группирует запросы по пересечению выдачи, в мягком или связном режиме. |
| AI cluster naming | Даёт кластеру название, интент, тип и заголовок страницы, по желанию — тексты для Google Ads. |
| Export to file | Выгрузка xlsx / csv / json как шаг конвейера. |

Коннекторы:

| Коннектор | Ключ |
|---|---|
| OpenAI и OpenAI-совместимые (OpenRouter, DeepSeek, Ollama, LM Studio) | нужен; для локальных моделей не нужен |
| Anthropic Claude | нужен |
| XMLRiver и Serper.dev (выдача Google) | нужен |
| Google Autocomplete | не нужен |

## Свой шаг за 20 строк

Положите `.py`-файл в `sito-data/plugins/` и перезапустите sito, шаг появится в меню *Add step*.
Пример и полный API описаны в [Writing plugins](src/sito/docs/writing-plugins.md).

## Ключи и безопасность

- Ключи хранятся в локальной базе `sito-data/sito.db` и никогда не отправляются обратно в браузер.
  Вместо самого ключа можно указать ссылку на переменную окружения: `env:OPENAI_API_KEY`.
- В sito **нет авторизации**. По умолчанию приложение слушает только `127.0.0.1`, а
  docker-compose публикует порт тоже только на localhost. Не открывайте его в сеть без
  прокси с авторизацией.
- Запросы с чужих сайтов (CSRF) и обращения по неизвестному имени хоста (DNS rebinding) sito
  отклоняет. Если сменить адрес подключения, ключ придётся ввести заново: сохранённый ключ никогда
  не уйдёт на новый адрес незаметно.
